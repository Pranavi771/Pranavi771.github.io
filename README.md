# Pranavi Joshi — Portfolio

Personal portfolio website for Pranavi Joshi, an Electronics & Communication Engineering undergraduate specialising in AI & ML at MIT World Peace University.

## Run locally
Open `index.html` in a modern browser. All assets are local except web fonts loaded from Google Fonts.

## Deploy on GitHub Pages
1. Upload the contents of this folder to the **root** of `Pranavi771/Pranavi771.github.io` (not the ZIP itself).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`, then save.
5. Wait for the Pages deployment to complete. The site URL will be `https://pranavi771.github.io/`.
